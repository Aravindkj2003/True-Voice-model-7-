ABSTRACT   
The  rapid  advancement  of  generative  artificial  intelligence  has  made  synthesizing  
highly
 
realistic
 
human
 
speech
 
easily
 
accessible,
 
leading
 
to
 
a
 
significant
 
rise
 
in
 
voice
 
cloning
 
and
 
audio-based
 
fraud.
 
This
 
project
 
proposes
 
a
 
comprehensive
 
Deepfake
 
Audio
 
Detection
 
System
 
designed
 
to
 
accurately
 
classify
 
speech
 
clips
 
as
 
either
 
Real
 
(Bona-fide)
 
or
 
Fake
 
(Spoof).
 
The
 
system
 
bridges
 
the
 
gap
 
between
 
digital
 
signal
 
processing
 
and
 
computer
 
vision
 
by
 
transforming
 
one-dimensional
 
audio
 
signals
 
into
 
two-dimensional
 
Mel-spectrograms.
 
The  core  classification  engine  utilizes  a  ResNet-18  convolutional  neural  network  
architecture,
 
leveraging
 
transfer
 
learning
 
to
 
extract
 
deep
 
hierarchical
 
features
 
from
 
the
 
audio
 
spectrograms.
 
To
 
ensure
 
robust
 
performance,
 
the
 
model
 
employs
 
a
 
two-stage
 
optimization
 
strategy
 
consisting
 
of
 
an
 
initial
 
warmup
 
phase
 
and
 
subsequent
 
fine-tuning.
 
Additionally,
 
SpecAugment
 
and
 
weighted
 
cross-entropy
 
loss
 
are
 
implemented
 
to
 
handle
 
data
 
augmentation
 
and
 
class
 
imbalances.
 
Beyond  the  machine  learning  pipeline,  the  project  includes  a  production-ready  web  
application
 
featuring
 
a
 
Flask-based
 
REST
 
API
 
and
 
a
 
responsive
 
React
 
frontend.
 
This
 
allows
 
users
 
to
 
upload
 
audio
 
files
 
and
 
receive
 
real-time
 
authenticity
 
predictions
 
with
 
confidence
 
scores.
 
Evaluated
 
using
 
security-oriented
 
metrics
 
such
 
as
 
Equal
 
Error
 
Rate
 
(EER)
 
and
 
Area
 
Under
 
Curve
 
(AUC),
 
the
 
system
 
demonstrates
 
high
 
validation
 
accuracy,
 
making
 
it
 
a
 
reliable
 
tool
 
for
 
digital
 
forensics
 
and
 
media
 
verification.

5.7  MATHEMATICAL  FORMULATION   5.7.1  Weighted  Cross-Entropy  Loss   To  handle  minute  class  imbalances  and  penalize  specific  misclassifications  
aggressively,
 
the
 
system
 
implements
 
a
 
Weighted
 
Cross-Entropy
 
loss
 
function:
 L  =  -  Σ  [  w_y  *  log(p_y)  ]  where  'w_y'  represents  the  calculated  weight  for  the  true  class,  and  'p_y'  is  the  predicted  
probability.
  5.7.2  Equal  Error  Rate  (EER)   Unlike  standard  accuracy,  EER  identifies  the  strict  operating  threshold  where  the  False  
Alarm
 
Rate
 
(FAR)
 
matches
 
the
 
False
 
Negative
 
Rate
 
(FNR).
 
The
 
system
 
evaluates
 
EER
 
mathematically
 
as:
 EER  =  min  |  FAR( τ)  -  FNR( τ)  |  By  locating  this  intersection  on  the  ROC  curve,  we  ensure  the  system  is  tuned  for  
forensic
 
security
 
standards
 
rather
 
than
 
generic
 
classification.
